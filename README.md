# Relative URL Extractor — Bookmarklet

Extract all relative URLs from any webpage instantly.

## Preview

![Relative URL Extractor](https://github.com/pushkarpa/Endpoint-finder/blob/main/Screenshot.png)
![Relative URL Extractor](https://github.com/pushkarpa/Endpoint-finder/blob/main/Screenshot2.png)


## How to install

1. Copy the script below
2. Create a new bookmark in your browser
3. Paste it as the bookmark URL
4. Click it on any page
